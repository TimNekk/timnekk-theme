# Changelog

Notable changes to TimNekk Theme are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Changed

- Expand the README with installation instructions, the color palette, Git status colors, customization examples, and local development steps.
- Organize this changelog by release, with dated entries and version comparison links.

## [1.0.2] - 2026-10-09

### Added

- Explicit Git decoration colors for renamed files, staged deletions, and submodules.

### Changed

- Use the string color (`#c3e88d`) for untracked files instead of gray.
- Remove transparency from deleted-file and merge-conflict colors to make them more visible.
- Reduce the size of the extension icon and preview image without changing their appearance.

## [1.0.1] - 2026-03-28

### Added

- A screenshot of the theme in the README.

## [1.0.0] - 2026-03-28

### Added

- Automated packaging and publishing to VS Code Marketplace, Open VSX, and GitHub Releases.
- Marketplace metadata, including publisher, search keywords, and gallery banner styling.

### Changed

- Set the minimum supported VS Code version to 1.87.0.

## [0.0.2] - 2025-03-03

### Added

- An extension icon and author information.

### Changed

- Update the extension description and README to introduce the theme and its Material Darker inspiration.
- Lower the declared minimum VS Code version from 1.97.0 to 1.0.0.

## [0.0.1] - 2025-03-03

### Added

- Initial release of TimNekk Dark, with editor and interface colors, syntax highlighting, terminal colors, and Git decorations.
